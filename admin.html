🔑 Masuk dengan Token GitHub

Token dibutuhkan sekali agar panel bisa mengunggah foto & menyimpan dokumen ke repository Anda. Token hanya disimpan di browser ini (localStorage) dan tidak dikirim ke pihak lain selain GitHub.

Cara membuat token (2 menit, sekali saja)
  1. Buka GitHub → Settings → Developer settings → Fine-grained tokens
  2. Token name: bebas, mis. panel-ppg
  3. Repository access → Only select repositories → pilih tugas-ppg
  4. Permissions → Repository permissions → Contents → Access: Read and write
  5. klik Generate token, salin token-nya (mulai github_pat_)
  6. Tempel di kolom atas → Simpan & Masuk

Token bisa dicabut kapan saja dari halaman GitHub yang sama (button Revoke).

Pilih foto → atur dengan geser & zoom di dalam bingkai (bingkai sudah sesuai rasio slot) → Simpan & Kirim. Foto otomatis dirapikan ukurannya, dinamai benar, lalu terunggah ke situs (±1 menit sampai tampil).

Tempel link Google Drive (akses: Anyone with the link) — ID file otomatis diambil. Klik Pratinjau untuk mengecek. Tekan Simpan Semua untuk menerapkan ke situs.

Tambahkan video YouTube (youtu.be/..., youtube.com/watch?v=..., Shorts) atau Google Drive (drive.google.com/file/d/...) untuk section Video Mengajar.

Atur Foto

Seret foto dengan mouse / jari untuk menggeser. Zoom hanya untuk memperbesar — seluruh bingkai pasti terisi foto (tidak ada garis kosong).
